| Id | Change | Source |

- Commits: rooflang 838541f; simthesizer 7fc31a3. Scheduler capacity is now
  read from the preset (`preset_capacity_bytes`) instead of a duplicated table.
- Consequences: Qwen3-235B EP4/TP1 no longer fits H200 (test moved to B300);
  agent scenario TOMLs (`agents/*/scenarios/shared-workload.toml`) on the
  branch use `device_mem = 141000000000` — their earlier sealed baselines are
  not comparable with this branch.
- Effect: E0002 — H200 prefill ≥8k (or batched) slower by up to 1.36–1.38×
  vs native-FP4 pricing; decode unchanged (HBM-bound).
- Alternative not chosen: W4A8 at FP8 rate (requires FP8 activation
  quantization = semantics change → mechanism candidate with quality flag).
